- Duplicatas com prefixos “Cópia de” foram removidas por nome original e tamanho.
- O exemplar de maior resolução disponível foi preservado em `originals/`.
- HEIC e DNG foram convertidos para WebP com dimensão máxima de 2560 px e qualidade 86.
- Os masters HEIC/JPEG/DNG permanecem intactos em `experiences/imersao-paranoa/originals/`.

Os arquivos de `backgrounds/` são cópias semanticamente nomeadas de fotos oficiais, prontas para uso no layout.
